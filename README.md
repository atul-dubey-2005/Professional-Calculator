# 🧮 Professional Calculator

A modern and responsive calculator application built using **HTML**, **CSS**, and **JavaScript**. It performs basic arithmetic operations with a clean user interface, keyboard support, and responsive design.

## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 💯 Percentage Calculation
- ⌫ Delete Last Character
- 🗑️ All Clear (AC)
- ⌨️ Keyboard Support
- 📱 Fully Responsive Design
- ⚡ Fast and Lightweight
- ⚠️ Invalid Expression Handling

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/atul-dubey-2005/Professional-Calculator.git
```

### Navigate to the project

```bash
cd Professional-Calculator
```

### Run the project

Simply open **index.html** in your web browser.
